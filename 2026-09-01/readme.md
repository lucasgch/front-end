# Exercício 

1. Clone o repositório enviado na aulas anterior
2. Crie uma nova página. Ela deve ser acessado a partir da página inicial através de um link “Ícones da saga”.
3. Cada ícone deve conter: imagem, nome, universo(filme, série, etc.)
4. Organize os ícones da saga em um layout de grid.
5. O grid deve ter pelo menos 20 ícones
6. Distribua os ícones da saga no grid (linhas e colunas) como desejar.
7. Crie uma barra superior fixa visível durante a rolagem.
