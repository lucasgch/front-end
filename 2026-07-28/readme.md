# Exercício 1

1. Crie um documento HTML completo com `<body>` e `<head>`.
2. Adicione um título com o seu nome e um parágrafo com uma breve descrição sobre você.
3. Adicione três divisões no documento. Em cada divisão, escreva o nome de uma saga que você gosta como título e, logo abaixo, um parágrafo explicando um pouco sobre ela.
